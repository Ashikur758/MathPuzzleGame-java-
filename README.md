# MathPuzzleGame

A simple Java console-based math puzzle game for elementary students. The game reads arithmetic questions from a file, asks the player to answer them, and keeps track of scores based on difficulty level.

## Features

- Console-based interactive game
- Supports multiple difficulty levels: Easy, Medium, Hard
- Reads questions from `questions.txt`
- Scores saved to `scores.txt`
- Handles invalid input safely
- `Ans:` prompt for user input without extra spaces
